# 小鲸鱼雷达 · astrbot_plugin_whale_radar

让**群聊里的机器人按「人格的日常爱好」主动插话**，而不是纯随机开火。

AstrBot 内置的主动回复只有一条 `possibility_reply` 随机数，不看话题；这个插件补上「看话题」的那一半：
每条没唤醒她的群消息都会被扫一眼，命中「她感兴趣的词」就按方向权重提高插话概率，没命中时还可以用便宜模型打 0-10 分。
被 @ / 唤醒词 / 指令命中的消息一律放过，绝不抢正常对话。

举例（人格：爱吃大白饭、打游戏、看股票、熬夜上班的群友）：

```
群友：刚数了下这周A股亏的钱，够买好几箱大白饭了
   → 命中 股票(A股) + 吃饭(大白饭) → p=0.90 → 她插一句「那还是大白饭实在，至少它不会绿。」
```

## 特性

- **按方向配权重**：股票 / 游戏 / 吃饭 / 熬夜上班 / 硬件代码 / 二次元 / 猫狗鲸鱼……每个方向一个权重，命中越多概率越高（每多命中一词 +12%，封顶 97%）。
- **可选打分**：关键词没命中时，可以让一个便宜模型对「最近几条消息」打 0-10 分，够阈值才插话；同一话题 2 分钟内复用分数，不重复烧钱。
- **自动学新爱好**：攒够 N 条群消息后，让模型从聊天里挑几个「她真会想接话的新词」，自动加进「新发现」方向；也可以在对话里由主模型自己调 `remember_interest` 记词。
- **防复读**：冷却时间、每日上限、连续说话抑制（上一句刚由她说的，下一条不抢）。
- **全部能在 QQ 里改**：`/雷达` 系列指令加词、删词、改方向权重、改概率、跑测试，改完立刻生效并落盘；也能在 WebUI 插件配置里可视化编辑方向。
- **零额外依赖**：只用标准库 + AstrBot 自带 API。

## 安装

1. 插件市场搜索 `小鲸鱼雷达`，或把本仓库放进 `AstrBot/data/plugins/astrbot_plugin_whale_radar/`。
2. 重载插件（WebUI 插件页 → 重载，或重启 AstrBot）。
3. 打开插件配置：
   - `operator_uids` 填你自己的 QQ 号（只有这些人能用 `/雷达` 改配置）。
   - `whitelist` 填要生效的群号（留空 = 所有群）。
   - 内置 `主动回复` 请把 `possibility_reply` 调成 0，避免两套逻辑重复回复。

装好就能用：自带 6 个通用方向（游戏 / 二次元 / 吃喝 / 股票 / 上班熬夜 / 硬件代码，共 32 个词），
点开 WebUI 配置按你自己的人设改词即可，不用从空白开始。

## 指令速查

```
/雷达                     看当前状态
/雷达 词                  看所有方向 + 权重 + 词数
/雷达 加词 股票 涨停 板了   往方向里加词（方向不存在就新建）
/雷达 新方向 熬夜 70%       新建方向
/雷达 方向 股票 85%         改方向权重
/雷达 设 基础 3%            改基础概率
/雷达 测试 今天A股又跌了      看这句话会怎么判、概率多少
/雷达 学 / 立刻学 / 学习记录  自动学词相关
/雷达 导出                 导出方向配置
```

完整列表发 `/雷达 帮助`。

## 主要配置项

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enable` | true | 总开关 |
| `whitelist` | `[]` | 生效的群号（空 = 全部） |
| `operator_uids` | `[]` | 能改配置的 QQ 号 |
| `keyword_groups` | 6 个方向 / 32 词 | 方向名 + 权重 + 词表，WebUI 可视化编辑 |
| `base_probability` | 0.02 | 什么都没命中时的随机插话概率 |
| `strong_probability` | 0.9 | 一个方向命中 ≥2 词时的概率 |
| `judge_enable` | true | 是否启用 0-10 打分 |
| `judge_threshold` | 7 | 多少分以上才插话 |
| `judge_cache_seconds` | 120 | 同话题复用打分的时长 |
| `cooldown_seconds` | 120 | 两次插话的最小间隔 |
| `daily_limit` | 40 | 每群每天最多插几次 |
| `learn_enable` | true | 自动学新爱好 |
| `learn_min_messages` | 60 | 攒够多少条群消息分析一次 |
| `learn_notify_uid` | `""` | 学到新词私聊通知谁 |

## 成本

除正常对话外，只有两处额外调用，且都可关：

- 打分：命中关键词的消息**不**打分；只有「没命中 + 消息够长 + 群里已有来回 + 每分钟未超限」才会问一次模型，输出只有 1 个数字，且在 `judge_cache_seconds` 内同话题复用。
- 学词：默认每 60 分钟、攒够 60 条消息才分析一次，每次最多学 2 个词。

按 DeepSeek 系模型的常见价格，一个活跃群一天的额外成本通常在几分钱以内。

## 隐私与边界

- 插件只**读取**群消息文本（用于判断与学词），不落库、不上传；聊天记录仅保存在内存里，重启即清空。
- 学词会把最近的聊天片段发给**你自己配置的模型**（和正常对话走同一个 provider）。
- 不会自动回复私聊，不会 @ 人，不会发图片。
